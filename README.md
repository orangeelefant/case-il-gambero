# Case study — Il Gambero

Samma case finns i samlingen [case-studies/il-gambero](https://github.com/orangeelefant/case-studies/tree/main/il-gambero).

How [Il Gambero](https://ilgambero.se) worked online in the version [Webraketen](https://webraketen.se) built, which is the version this case describes. The site now live at ilgambero.se is run by Il Gambero on One.com Web Editor, a platform Webraketen does not run.

## Om Il Gambero

Il Gambero är en napoletansk pizzeria i centrala Göteborg, etablerad 1995 och numera på Storgatan 11. Vi gör äkta surdegspizza enligt napoletansk tradition med långjäst deg och italienska råvaror. Med 30 års rykte i Göteborg är vi ett självklart val för dig som vill ha genuin pizza napoletana. Boka bord eller hämta hos oss på Storgatan 11.

→ [ilgambero.se](https://ilgambero.se)
